# AI 科创实验室项目需求说明

## 一、项目背景

本项目拟建设一个面向中小学生科学教育与科技教育场景的交互式学习平台。平台以 Web 技术和 Three.js 为基础，将三维模型展示、科学实验任务与智能学习辅助相结合，帮助学习者通过观察、操作和问题引导理解科学知识。

项目的具体需求将通过后续用户访谈、问卷调查和试用测试进一步验证。

## 二、项目目标

1. 建设可在普通浏览器中访问的科学教育平台。
2. 实现科学模型的三维展示与交互。
3. 将科学知识组织成课程和实验任务。
4. 逐步接入 AI 科学导师，为学习者提供知识解释和任务提示。
5. 记录学习过程，并通过数据分析辅助评估学习效果。
6. 探索低成本、易访问的科学教育资源普惠方案。

## 三、目标用户

第一阶段主要面向对科学探索感兴趣的中小学生。

教师可以作为后续扩展的辅助用户，用于组织课程、查看学习记录和了解实验完成情况。

目标用户的具体年龄范围、设备条件和学习需求需要通过调研进一步确认。

## 四、核心功能

### 4.1 首页与课程入口

展示项目介绍、课程入口和实验室入口。

### 4.2 3D 科学实验室

支持科学模型展示、旋转、缩放、选择对象和查看知识说明。

### 4.3 科学课程与实验任务

提供课程介绍、学习目标、操作步骤和知识测验。

### 4.4 AI 科学导师

在完成基础实验功能后接入大模型 API，为用户提供知识讲解、引导问题和实验提示。

### 4.5 学习记录与数据分析

记录实验完成状态、测验结果和必要的学习行为，并提供基础统计。

### 4.6 作品管理

后续支持模型导入、作品保存和下载，并逐步验证 AI 3D 生成能力。

## 五、第一版开发范围

第一版优先完成：

1. 前端工程初始化。
2. 首页和基础页面布局。
3. 一个可交互的 3D 科学场景。
4. 至少一个完整的课程与实验任务。
5. 基础测验和学习记录。
6. 项目文档与可重复运行的演示版本。

AI 3D 生成、用户账户系统、VR、多人协作和复杂 3D 打印功能暂不作为第一阶段的必需项。

## 六、技术方案

前端使用 HTML、CSS、JavaScript、Vite 和 Three.js。

后端计划采用 Python 与 FastAPI。

第一版数据存储采用 SQLite，后续根据实际使用规模考虑迁移至 MySQL。

AI 能力优先通过合规的第三方 API 集成，具体服务依据可用接口、成本和效果测试确定。

## 七、非功能需求

1. 页面应能适配常见桌面浏览器及移动设备。
2. 对不支持的文件格式和异常请求提供明确提示。
3. API 密钥不得直接暴露在前端或公开仓库中。
4. 尽量减少不必要的个人信息收集。
5. 项目应提供清晰的安装、启动和部署说明。
6. 课程内容和 AI 输出应进行科学准确性检查。

## 八、项目验证计划

通过目标用户访谈、原型试用、任务完成率、知识测验和问卷等方式评估产品可用性与学习效果。

在收集数据前明确告知参与者用途，涉及未成年人时遵循适用的监护人同意、隐私保护和研究伦理要求。

所有研究结论以真实收集的数据为依据，不预先设定或编造项目效果。

## 九、阶段性成果

第一阶段：完成工程骨架、首页和项目文档。

第二阶段：完成基础 3D 科学场景。

第三阶段：完成课程、实验任务和测验。

第四阶段：完成后端、AI 辅助与学习记录。

第五阶段：开展试用、分析结果并持续优化。
