# AI 科创实验室

面向科学教育与科技教育场景的交互式学习平台，尝试将 Web 3D、科学实验任务和 AI 学习辅助相结合，让抽象的科学知识更直观、更容易探索。

## 项目目标

- 构建浏览器端 3D 科学探索环境。
- 将科学知识组织成课程与实验任务。
- 探索 AI 在科学知识讲解和学习引导中的应用。
- 通过真实用户测试评估平台的可用性与教育价值。

## 本地运行

### 1. 环境要求

- Node.js LTS
- npm
- Git

### 2. 克隆项目

```bash
git clone 你的仓库地址
cd 你的项目文件夹
```

### 3. 安装依赖

```bash
npm install
```

### 4. 启动开发服务器

```bash
npm run dev
```

根据终端显示的本地地址，在浏览器中打开项目。

### 5. 构建项目

```bash
npm run build
```
