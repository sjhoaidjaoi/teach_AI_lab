# AI 科创实验室

面向科学教育与科技教育场景的交互式学习平台，尝试将 Web 3D、科学实验任务和 AI 学习辅助相结合，让抽象的科学知识更直观、更容易探索。

## 项目目标

- 构建浏览器端 3D 科学探索环境。
- 将科学知识组织成课程与实验任务。
- 探索 AI 在科学知识讲解和学习引导中的应用。
- 通过真实用户测试评估平台的可用性与教育价值。

## 技术栈

## 本地运行

### 1. 环境要求

- Node.js LTS
- npm
- Git

### 2. 克隆项目

```bash
git clone 你的仓库地址
cd 你的项目文件夹
```

### 3. 安装依赖

```bash
npm install
```

### 4. 配置环境变量

在项目根目录创建 `.env` 文件，填入 DeepSeek API 密钥：

```text
DEEPSEEK_API_KEY=你的密钥
```

`.env` 已在 `.gitignore` 中忽略，不会被提交。

### 5. 启动后端服务

AI 学习导师依赖本地后端代理接口（端口 3001）：

```bash
npm run server
```

### 6. 启动前端开发服务器

```bash
npm run dev
```

根据终端显示的本地地址，在浏览器中打开项目。前端会通过 Vite 代理把 `/api` 请求转发到 `http://localhost:3001`。

### 7. 构建项目

```bash
npm run build
```

## 虚拟实验平台（多学科 · 可操作 · 可测量 · AI 引导）

设计原则：**实验现象与测量值由可验证的科学公式和实验规则计算，DeepSeek 只负责讲解、引导、分析与反馈，计算逻辑与 AI 对话逻辑严格分离**，避免 AI 编造实验现象或数据。

- 统一五区页面：A 实验信息区 · B 虚拟操作区 · C 数据测量区 · D AI 实验导师区 · E 实验记录区。
- 实验模块契约 v2：每个实验模块自带"规则引擎 + 操作界面 + 测量界面"，实验台只做通用框架；新增实验只需在 `src/experiments/catalog.js` 注册并提供一个模块目录。
- 已上线（四大学科全部可操作）：
  - **物理（初中）· 探究串联电路中的电流规律**：B 区默认"3D 实验台"——在三维场景中点击两个接线柱连接导线、点击导线拆除、点击开关通断，电流粒子沿真实接线流动，电流表标记悬浮在所选测量点上方；可一键切换"2D 电路图"视图（接线状态保留）。通路/断路/短路/非规范串联由图分析规则实时判定，按 $I=U/R$ 计算电流与分压；A/B/C 三处电流表读数与多组数据表。
  - **化学（初中）· 酸碱指示剂与溶液性质**：6 种模拟溶液 × 石蕊/酚酞滴加，颜色由验证过的变色规则表查表得出，观察记录表自动判定酸碱性。
  - **生物（初中）· 显微镜观察细胞**：目镜/物镜/粗准焦/光圈按光学规则模拟（总倍率=目镜×物镜，焦距偏差决定清晰度），程序绘制洋葱表皮与口腔上皮标本，结构标注即时判分。
  - **地理（初中）· 地球公转与四季形成**：2D 公转模型，直射点 δ=23.5°·sin θ、正午太阳高度 H=90°−|φ−δ|、昼长 L=12+(24/π)·arcsin(tan φ·tan δ) 全部由公式实时计算，支持多城市×四节气数据对比。
  - **太阳系 3D 观察**：原 Three.js 场景作为地理拓展观察入口。
- 后端接口：`POST /api/experiment/guide`（AI 仅依据规则引擎实时数据讲解，系统提示词禁止其计算/修改/编造数值）、`POST /api/experiment/report`（实验报告草稿，按通用表格 records 原样整理真实数据）。

## 3D 科学实验室（多场景切换）

遵循"适合 3D 的进 3D、适合平面的留平面"原则，`3D 实验室`页面（`#laboratory`）提供三个可切换的 Three.js 场景，`#laboratory/circuit`、`#laboratory/seasons` 可直达：

- **太阳系探索**：旋转/缩放/点击天体查看数据（原有场景）。
- **串联电路 3D 演示**：电池、开关、灯泡、电流粒子的三维可视化；电压/电阻可调，电流、分压与灯泡亮度由串联电路规则引擎按欧姆定律计算，点击场景中的开关可通断电路。
- **地球公转 3D 演示**：地轴倾斜 23.5° 且方向不变、公转动画、太阳直射点标记与直射光线；直射点纬度/正午太阳高度/昼长由天文学公式实时计算，支持节气拖动与城市选择。

两个 3D 实验场景以 `three-view.js` 懒加载模块放在各自实验目录内，复用对应实验的 `rules.js`，3D 层不做任何科学计算。串联电路另有 `three-operation.js`（实验台 B 区的 3D 可操作实验台，同样只消费规则引擎结果）。实验目录卡片的"🧊 3D 演示"按钮与实验台 B 区的"在 3D 实验室查看"入口可互相跳转。

串联电路与地球公转场景的右侧面板内置"观察任务"清单：学生完成调参、闭合开关、切换城市等操作后，对应任务自动打勾，让 3D 观察带有明确的动手目标。

## 页面与导航

导航精简为 6 项：首页 / 虚拟实验 / 实验指导 / AI 导师 / 智能测评 / 学习分析。3D 实验室已并入虚拟实验：目录页 hero 提供"🧊 进入 3D 实验室"入口，实验台 B 区可直达对应场景。

- **虚拟实验**（`#experiments`）：四大学科实验目录，可筛选；串联电路实验台 B 区内置"3D 实验台 / 2D 电路图"双视图切换（默认 3D，接线状态跨视图保留）。
- **3D 实验室**（`#laboratory`，不再占用主导航）：太阳系 / 串联电路 / 地球公转场景切换。
- **实验指导**（`#experiment`）：顶部提供虚拟实验直达卡片；先从平台已有的可操作实验中选定一个，AI 依据该实验注册表中的学习目标、原理、器材、安全提示与模块步骤生成专属实验方案，再按"准备 → 分步操作 → 观察记录 → AI 分析"流程推进；方案页与分步页可直达该实验的 3D 场景或虚拟实验台。课程任务中心作为子页保留（`#courses`，不再占用主导航）。
- **智能测评**（`#quiz`）：仅可选择**已经学过**的实验（本机存在实验台操作记录才可生成，未学实验锁定并引导先做实验）；生成时自动把该实验已保存的真实测量数据表注入命题上下文，出数据分析类题目；后端对记录只做原样传递，禁止模型改写数据。测评记录携带实验标识，供单实验分析筛选。
- **学习分析**（`#dashboard`）：保留总体框架（统计卡、任务/成绩/薄弱点/时长四图、AI 复习建议、错题本、反馈、导出）；"各实验学习分析"板块的实验卡片可点击进入**单实验详情**：步骤完成清单（复用实验模块规则引擎判定口径）、真实测量数据表、实验结论、AI 实验报告、近期操作日志、该实验测评记录，以及继续实验/3D 场景/再测评快捷入口，可一键返回总览。旧"学习记录"页（`#records`）已并入学习分析。
- 全站样式统一：吸顶导航胶囊高亮、卡片悬停反馈、统一设计变量（圆角/阴影/主色）；已完成可读性专项修复（次级按钮深浅色背景自适应、说明文字加深、目录卡片浅色化、深色面板控件配色），保证投屏与低亮度屏幕下可读。
- 首页提供平台数据一览条（学科数、可操作实验数、3D 场景数，由实验注册表真实统计）。
